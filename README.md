# 쌤톡스 (v0.3)

> 메시지 홍수·학부모 연락·학급 일정에서 잠시 벗어나는 교사용 디톡스 앱.
> 폰과 PC를 계속 지켜보지 않아도, 쌤톡스가 알림을 모아 두었다가 정해진 시각에 정리해 드려요.

휴대폰에 온 알림을 모아 두었다가, 폰 안에서 도는 Gemma 4 E4B로 "오늘 알림 브리핑"을 만들어 주는 앱.
인터넷 권한이 없어서 데이터가 폰 밖으로 나가지 않습니다.

## 폰에서 앱(APK) 받기
항상 최신 버전을 받는 고정 링크 (폰 브라우저에서 북마크·홈 화면에 추가해 두면 편해요):

**https://github.com/01056649000yoo/Phonejarvis/releases/latest/download/SsamTox.apk**

받은 뒤 **업데이트**로 덮어 설치하면 모델과 기록은 그대로 남아요.

## 첫 실행 설치 안내 (v0.3)
앱을 처음 열면 4단계 안내가 나와요. 아래 "모델 받기"를 손으로 할 필요가 없어요.
1. **소개** — 쌤톡스가 하는 일
2. **폰 진단** — 기기·칩·램·남은 저장공간을 확인하고 모델을 추천 (램 12GB 이상 + 저장공간 넉넉 → Gemma 4 E4B, 그 외 → Gemma 4 E2B. 기본값은 E2B)
3. **모델 받기** — "다운로드 시작"으로 브라우저에서 받고, "파일 선택"으로 다운로드 폴더의 파일을 가져옴 (앱은 인터넷 권한이 없어서 브라우저를 씀)
4. **권한** — 알림 접근, 알림 표시

이미 모델이 설치된 폰(예전 버전에서 업데이트)은 안내를 건너뛰고 바로 메인 화면이 열려요. 모델 파일을 이미 다운로드 폴더에 받아 뒀다면 3단계의 **🔎 이미 받아 둔 모델 찾기**로 자동으로 찾아 가져와요 ("모든 파일 접근" 권한을 한 번 켜야 함, 인터넷 권한이 없어 파일은 밖으로 나가지 않음). 메인 화면의 ② AI 모델 → **바꾸기**로 언제든 진단 단계부터 다시 할 수 있어요.

## 설치 순서 (Galaxy Z Fold4 기준)

### 1. PC 준비
1. Android Studio 설치: https://developer.android.com/studio
2. 이 폴더(`jarvis`)를 압축 해제 → Android Studio → **Open** → `jarvis` 폴더 선택
3. 처음 열면 Gradle 동기화로 라이브러리를 내려받습니다 (5~10분). 아래 "Sync" 진행 표시가 끝날 때까지 대기
   - AGP 업그레이드 권유 창이 뜨면 **나중에(Don't remind / Cancel)** 를 눌러도 됩니다

### 2. 폰 준비
1. 설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드번호 7번 탭** → 개발자 모드 켜짐
2. 설정 → 개발자 옵션 → **USB 디버깅** 켜기
3. USB로 PC 연결 → 폰에 뜨는 "USB 디버깅 허용" → 허용

### 3. 앱 설치
Android Studio 상단에서 기기(SM-F936N 등)가 선택된 것 확인 → ▶ **Run** 버튼

### 4. 모델 받기 (폰에서)
1. 폰 브라우저로 https://huggingface.co/litert-community/gemma-4-E4B-it-litert-lm → **Files** 탭
2. `gemma-4-E4B-it.litertlm` (약 3.7GB) 다운로드 — 와이파이에서
3. 쌤톡스 앱 → ② **파일 선택** → 다운로드 폴더에서 그 파일 선택 → 복사 완료까지 대기 (2~3분)
   - 복사가 끝나면 다운로드 폴더의 원본은 지워도 됩니다

### 5. 알림 권한
1. 쌤톡스 앱 → ① **설정 열기** → 쌤톡스 켜기
2. **"제한된 설정" 때문에 회색으로 잠겨 있으면**: 설정 → 애플리케이션 → 쌤톡스 → 오른쪽 위 ⋮ → **제한된 설정 허용** → 다시 1번

### 6. 사용
권한을 켠 **이후에** 오는 알림부터 수집됩니다. 알림이 좀 쌓이면 "오늘 알림 요약하기"를 누르세요.

## 문제 해결
| 증상 | 해결 |
|---|---|
| 요약 중 token/context 관련 오류 | `Summarizer.kt`의 `CHUNK_CHARS`를 1000으로 낮추기 |
| GPU 실패 후 CPU로 느리게 동작 | 정상 동작(폴백). 상태 문구로 확인 가능 |
| 알림이 수집 안 됨 | 설정 → 배터리 → 백그라운드 사용 제한 → 쌤톡스를 "절전 예외 앱"에 추가 |
| 특정 앱 알림을 빼고 싶음 | `NotificationCollectorService.kt`의 `IGNORED_PACKAGES`에 패키지명 추가 |
| `litertlm-android:latest.release` 동기화 실패 | Maven에서 최신 버전 번호를 확인해 고정 버전으로 교체 |

## 파일 구조
- `NotificationCollectorService.kt` — 알림 수집 (광고성 상시알림·묶음요약 제외)
- `NotificationDb.kt` — SQLite 저장, 7일 지나면 삭제
- `Summarizer.kt` — 규칙 전처리 → Gemma 부분 요약 → 최종 브리핑
- `MainActivity.kt` — 화면 (권한·모델 상태, 자동 브리핑 설정, 요약 버튼, 수집 목록)
- `BriefingScheduler.kt` — 아침·저녁 시각 저장, 정확한 시각 알람 예약, 재부팅 시 재등록
- `BriefingService.kt` — 예약 시각에 요약 실행(포그라운드 서비스), 결과 알림, 브리핑 기록 저장

## 자동 브리핑 (v0.2)
1. 앱 → ③ **허용하기**로 알림 표시 권한 허용
2. ⏰ **자동 브리핑**에서 아침/저녁 시각을 눌러 바꾸고 스위치를 켬 (기본 08:00 / 21:00)
3. 정한 시각이 되면 **지난 브리핑 이후(최대 24시간)** 쌓인 알림을 요약해 알림으로 보내 줌. 앱 화면에도 마지막 브리핑이 남음
4. **지금 브리핑 받아보기**로 바로 테스트 가능 (진행 상황은 알림창에 표시)

- 정확한 시각 알람(AlarmManager) + 포그라운드 서비스로 동작해서 폰이 잠겨 있어도 실행됨. 재부팅해도 다시 예약됨
- 브리핑이 끝나면 모델을 메모리에서 내려 배터리·메모리를 아낌
- 시간이 안 맞거나 실행이 안 되면: 설정 → 애플리케이션 → 쌤톡스 → 배터리 → **제한 없음**
