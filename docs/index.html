자주 묻는 질문

눌러서 펼쳐 보세요.

학부모 연락 내용이 어디로 보내지나요?

어디로도 보내지지 않아요. 쌤톡스는 인터넷 권한 자체가 없는 앱이라, 알림 모으기와 AI 요약이 모두 폰 안에서만 이뤄져요.

매번 앱을 열어야 하나요?

아니요. 🔕 모아서 알림을 켜고 요약 시각을 정해 두면 그 시각에 알림으로 요약이 와요. 알림을 누르면 요약과 원문을 바로 볼 수 있고, 홈 화면 위젯에서도 볼 수 있어요.

모아 두는 동안 전화도 안 울리나요?

전화는 언제나 울려요. '소리도 끄기'는 메시지·알림 소리와 진동만 꺼요. 알람, 재난 문자, 인증번호 알림도 그대로 와요.

'소리도 끄기'를 켜니 권한 화면이 나와요.

메시지 소리를 끄려면 폰의 '방해 금지 접근' 권한이 한 번 필요해요. 목록에서 쌤톡스를 허용하고 돌아오면 돼요. 폰 설정의 모드 목록에 '쌤톡스 모아 두기'가 생기고, 모으는 동안만 켜져요. 선생님이 직접 켠 방해 금지는 건드리지 않아요.

모델 다운로드에 데이터 요금이 나오나요?

E4B는 3.7GB, E2B는 2.6GB라서 모바일 데이터로 받으면 요금이 나올 수 있어요. 와이파이에서 받아 주세요. 이미 받아 둔 파일이 다운로드 폴더에 있으면 앱이 찾아서 가져와요.

왜 Play 스토어가 아니라 APK로 설치하나요?

아직 개발 중인 무료 앱이라 직접 배포하고 있어요. 그래서 설치할 때 "출처를 알 수 없는 앱" 허용이 한 번 필요해요.

알림이 모이지 않아요.

알림 접근 권한이 켜져 있는지 확인하세요. 회색으로 잠겨 있으면 설정 → 애플리케이션 → 쌤톡스 → 오른쪽 위 ⋮ → 제한된 설정 허용 후 다시 켜요. 배터리 설정에서 쌤톡스를 "제한 없음"으로 두면 더 안정적이에요.

요약이 정한 시각에 안 와요.

설정 → 애플리케이션 → 쌤톡스 → 배터리 → 제한 없음으로 바꿔 주세요. 폰을 재부팅해도 예약은 저절로 다시 잡혀요. 정한 시각에는 새 알림이 없어도 '새 알림 없음'을 알려요. 위젯 위쪽 '⏰ 자동' 줄이나 설정 → 🔕 모아서 알림 → 📝 최근 자동 요약에서 실제로 돌았는지 볼 수 있어요.

예전에 온 문자를 다시 찾을 수 있나요?

네. 알림 탭 맨 위 🔎 검색 칸에 낱말을 치면 쌤톡스가 모아 둔 알림 전체에서 찾아 최근 것부터 보여 줘요. 띄어 쓰면 낱말이 모두 든 알림만 나와요. 얼마나 오래 남길지는 설정 → 🧹 저장 공간에서 3일~3개월 중에 골라요. 인증번호 알림은 처음부터 저장하지 않아 검색에도 나오지 않아요.

하루 정리는 언제, 어떻게 오나요?

매일 밤 10시에 한 번 와요. 설정 → 🔕 모아서 알림에서 시각을 바꾸거나 끌 수 있어요(모아서 알림을 꺼 두어도 따로 돼요). 그날 요약이 하나도 없으면 오지 않아요. 폰이 뜨겁거나 배터리가 적으면 AI 없이 간단히 합쳐서 보내요.

광고나 매일 오는 알림이 요약에 섞여요.

광고 문자는 키워드(내 이름 등)가 들어 있어도 걸러요. 대표번호(15xx·080·02 등)로 온 문자는 사람 연락이 아니라 📦 앱 알림으로 가고, 'OO님'처럼 이름을 부르기만 한 알림은 ⭐ 키워드 알림에 올리지 않아요. 날씨·서버 알림처럼 매일 비슷한 시각에 오는 알림과 봇 알림은 요약 끝에 🔁 건수 한 줄로만 적어요. 그 밖에 빼고 싶은 알림은 알림 탭에서 길게 눌러 '요약에서 빼기'를 하세요(같은 꼴의 알림이 모두 빠지고, 언제든 되돌릴 수 있어요).

가족·지인 연락은 어떻게 정리되나요?

설정에서 만든 👥 묶음(가족·교직원 등)에 넣은 사람은 카톡·문자·단톡방을 가리지 않고 같은 이름끼리 모아, 사람마다 핵심 한 줄과 부탁으로 정리해요.

요약이 더 빨리 나오게 할 수 있나요?

쌤톡스가 알아서 ⚡ 미리 요약을 해 둬요. 충전 중이면 새 메시지가 쌓일 때마다 10분 간격으로, 충전 중이 아니면 배터리가 30% 이상이고 요약할 메시지가 15개 이상 쌓였을 때 대화방마다 요점·요청을 미리 정리해 둬요. 화면이 꺼져 있을 때만 하고, 화면을 켜거나 폰이 따뜻해지면 멈춰요. 요약 시각에는 그 뒤에 온 메시지만 이어서 정리하니 훨씬 빨리 나와요. 한 사람이 여러 번 보낸 메시지는 하나씩 늘어놓지 않고 핵심 한 줄로, 부탁은 급한 것부터 2개까지 보여 줘요.

알림이 많으면 빠지는 대화방이 있나요?

없어요. 모든 대화방을 요약하고, 메시지가 30개가 넘는 방은 30개씩 차례로 읽으며 앞서 정리한 것에 이어서 고쳐 써요(한 방은 한 줄로).
