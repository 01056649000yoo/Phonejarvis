자주 묻는 질문

눌러서 펼쳐 보세요.

학부모 연락 내용이 어디로 보내지나요?

어디로도 보내지지 않아요. 쌤톡스는 인터넷 권한 자체가 없는 앱이라, 알림 모으기와 AI 요약이 모두 폰 안에서만 이뤄져요.

매번 앱을 열어야 하나요?

아니요. 요약 시각을 정해 두면 그 시각에 알림으로 요약이 와요. 알림을 누르면 요약과 원문을 바로 볼 수 있어요.

모델 다운로드에 데이터 요금이 나오나요?

모델이 2.6~3.7GB라서 모바일 데이터로 받으면 요금이 나올 수 있어요. 와이파이에서 받아 주세요.

왜 Play 스토어가 아니라 APK로 설치하나요?

아직 개발 중인 무료 앱이라 직접 배포하고 있어요. 그래서 설치할 때 "출처를 알 수 없는 앱" 허용이 한 번 필요해요.

알림이 모이지 않아요.

알림 접근 권한이 켜져 있는지 확인하세요. 회색으로 잠겨 있으면 설정 → 애플리케이션 → 쌤톡스 → 오른쪽 위 ⋮ → 제한된 설정 허용 후 다시 켜요. 배터리 설정에서 쌤톡스를 "제한 없음"으로 두면 더 안정적이에요.

요약이 정한 시각에 안 와요.

설정 → 애플리케이션 → 쌤톡스 → 배터리 → 제한 없음으로 바꿔 주세요. 폰을 재부팅해도 예약은 저절로 다시 잡혀요.
