알림을 조용히 모아요

카톡, 하이클래스, 업무메신저 등 폰에 오는 알림을 대신 모아 둬요. 광고·상시 알림은 걸러요.

정한 시각에 한 번만

아침 조회, 저녁 종례처럼 원하는 시각을 정하면 그때 한 번 브리핑을 알림으로 보내 줘요.

폰 안에서만 처리

요약은 폰에 받은 AI(Gemma)가 해요. 앱에 인터넷 권한이 없어서 학부모 연락이 밖으로 나가지 않아요.

사용 방법

처음 한 번만 설정하면 돼요. 앱이 단계별로 안내해 줘요 (약 10분).

  1. 앱 설치아래 버튼이나 QR로 APK를 받아 설치해요.
  2. 폰 진단 · AI 모델 추천램과 저장공간을 확인해서 이 폰에 맞는 모델(Gemma 4 E4B 또는 E2B)을 골라 줘요.
  3. 모델 받기와이파이에서 브라우저로 받아요 (2.6~3.7GB). 이미 받아 뒀다면 자동으로 찾아 가져와요.
  4. 권한 허용알림 접근(알림 모으기)과 알림 표시(브리핑 받기)를 켜요.
  5. 브리핑 시각 정하기아침·저녁 시각을 켜 두면 끝. 이제 폰을 내려놓으세요.

자주 묻는 질문

궁금한 점을 모았어요.

학부모 연락 내용이 어디로 보내지나요?

어디로도 보내지지 않아요. 쌤톡스는 인터넷 권한 자체가 없는 앱이라, 알림 수집과 AI 요약이 모두 폰 안에서만 이뤄져요. 수집한 알림은 7일이 지나면 자동으로 지워져요.

모델 다운로드에 데이터 요금이 나오나요?

모델이 2.6~3.7GB라서 모바일 데이터로 받으면 요금이 나올 수 있어요. 앱이 다운로드 전에 와이파이 연결을 확인하도록 안내해요.

왜 Play 스토어가 아니라 APK로 설치하나요?

아직 개발 중인 무료 앱이라 GitHub에서 직접 배포하고 있어요. 그래서 설치할 때 "출처를 알 수 없는 앱" 허용이 한 번 필요해요.

알림이 모이지 않아요.

알림 접근 권한이 켜져 있는지 확인하세요. 회색으로 잠겨 있으면 설정 → 애플리케이션 → 쌤톡스 → 오른쪽 위 ⋮ → 제한된 설정 허용 후 다시 켜요. 배터리 설정에서 쌤톡스를 "제한 없음"으로 두면 더 안정적이에요.

브리핑이 정한 시각에 안 와요.

설정 → 애플리케이션 → 쌤톡스 → 배터리 → 제한 없음으로 바꿔 주세요. 폰을 재부팅해도 예약은 자동으로 다시 등록돼요.
